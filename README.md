# 💫 About Me:
 Hi, I'm Mazen Sharaky — a Full-Stack Developer, Embedded Systems Engineer, DevOps Engineer, and AI Builder. I work on creating smart, scalable systems across software and hardware. I build full web applications using PHP, Laravel, Node.js, C#, and WPF, and I develop embedded and IoT systems using ESP32 and sensors. I also handle DevOps workflows including deployment, servers, CI/CD, and system automation. I'm part of Quantum Stack, where we deliver advanced systems for companies, hospitals, and startups. I enjoy solving complex problems, designing clean architectures, and building practical intelligent tools. Currently, I’m working on an AI system for companies and students, a complete hospital management system (Neuro Care), and a full smart home system using ESP32. My stack includes C++, PHP, JavaScript, Python, C#, Laravel, Node.js, WPF, MySQL, and MongoDB. You’ll usually find me learning something new, building a system from scratch, or optimizing an existing one. If you’d like to collaborate on IoT, AI tools, DevOps pipelines, or full web applications, feel free to reach out at: Sharakymazen@gmail.com<br>.
